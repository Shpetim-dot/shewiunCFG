Questions we hear first

What is Shewiun?

Shewiun is a web workspace for teams that put AI agents to work. Agents get their own permissions, memory and tools. People approve consequential actions, and everything is written to a tamper-evident audit log.

Who is it for?

Teams that already run or plan to run agents with write access: security and platform teams that have to sign off, and founders who want to ship agents without losing control. Financial services is our first focus.

Does Shewiun replace my model provider?

No. Bring any OpenAI-compatible endpoint or open models through Hugging Face Inference Providers. Without a model key the workspace runs scripted demo answers, clearly marked as such.

Can an agent act without approval?

Only if you allow it. Read access follows the permissions you set per agent. Write tools create an approval request that a person must accept, and secret-looking tools can never be granted.

How does the audit log prove anything?

Every event stores the hash of the previous one. The verify function recomputes the chain, so an edited or deleted entry breaks it. This shows tampering inside the log. It does not replace your own backups.

Is Shewiun certified, for example SOC 2?

Not yet. The trust page lists what is enforced today and what is not, and we can send our security questionnaire answers on request. We would rather tell you this plainly than imply a certificate.

Where is my data stored and can I leave?

Each organisation is isolated in its own scope. You can export all of your organisation data as JSON at any time from the Organisation page, and delete the organisation yourself. The privacy policy lists the processors we use.

How much does it cost and can I cancel?

The Free plan costs nothing. Paid plans are billed monthly through Stripe and you can cancel in the app, with changes taking effect at the end of the billing period. See the pricing section for current limits.

How fast do you answer questions?

We reply to every message within 1 business day. Use the contact form or the button on this page.
