# Customer value and evaluation metrics

These are proposed measurements, not achieved results. Recruit 3–5 design partners and obtain permission before collecting customer work or personal data. Use one validated workflow and compare the same task, inputs, source access, model/tool budgets and review standard across products.

| Metric | Definition | Evidence needed |
|---|---|---|
| Accepted deliverables | Deliverables accepted by a human / tasks started | Saved output, acceptance criteria and reviewer decision; show failures separately. |
| Time saved | Comparable manual task time minus total assisted time | Include human setup, review, correction and tool waiting, not only model latency. |
| Rework | Human correction minutes and rejected sections | Reviewer notes against versioned drafts. |
| Weekly repeat use | Consenting workspaces returning to the chosen workflow | Aggregated cohort counts; exclude bots, demos and internal testing. |
| Completion reliability | Verified completed tasks / all started tasks | Persisted terminal statuses; distinguish cancelled, partial, failed and unknown. |
| Recovery reliability | Interrupted runs resumed without duplicate side effects / interruption trials | Restart/timeout drills, checkpoints and idempotency evidence. |
| Evidence quality | Correctly supported claims / reviewed material claims | Blind human checks of original source passages; citation presence alone is insufficient. |
| Unsupported claims | Unsupported or contradicted claims / reviewed claims | Prespecified rubric and independent reviewer. |
| Cost per accepted result | Model, search and compute cost / accepted deliverables | Sourced prices and usage; unknown costs explicitly excluded and totals marked partial. |
| Human intervention | Review/approval/correction events and minutes per task | Separate intended approvals from avoidable rescue interventions. |
| Permission failures | Unauthorized actions attempted, blocked and executed | Adversarial regression tests and audit evidence; zero observed is not a proof of absence. |
| Willingness to pay | Explicit pilot conversion or interview evidence | Do not infer from clicks or set final prices without cost/customer evidence. |

For competitor benchmarks record product version/date, plan and region, task fixtures, constraints, rubric, reviewers, failures, cost coverage and raw artifacts. Never describe simulated landing-demo chat as a benchmark or customer outcome. No customer interviews, purchase tests or external benchmarks were conducted in Batch 0.
