# Competitive analysis

The maintained source ledger, evidence limitations and fair evaluation protocol are in [COMPETITORS.md](COMPETITORS.md), reviewed 2026-11-12.

CrewAI official materials include a managed control plane and governance. OpenClaw documents personal/shared assistants and configurable execution isolation. OpenAI Agents SDK includes provider-agnostic orchestration and human review. These capabilities are not unique to Shewiun.

User-provided Grok/CrewAI screenshots guide interaction and visual design, not security or performance claims. Grok Bots, ChatGPT, Dots and Town/Townies need additional authoritative product evidence as recorded in the ledger. No cross-product benchmark has been executed.

Business-first hypothesis: reduce the work between a client brief and an accepted, evidence-backed deliverable while keeping specialist agents within independently enforced permissions. Validate with design partners before claiming an advantage.
